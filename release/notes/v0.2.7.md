This maintenance release prevents the public site from returning a temporary 502 response after control-plane updates.

## Bug fixes

- Force-recreate only the Nginx service after API and Web containers have been replaced, refreshing Docker DNS resolutions without restarting the updated services again. ([#117](https://github.com/smartcat999/game-panel-lite/pull/117))
- Use the correct save-action label in account and node dialogs, and require matching new-password confirmation before submitting an account password change.

## Upgrade notes

No data or configuration migration is required. The control plane restarts briefly during the update. Running game server containers and save data are not recreated.

| Compatibility | Result |
| --- | --- |
| Data migration | Not required |
| Configuration migration | Not required |
| Game server restart | Not required |
| Control-plane restart | Required |
| Published platform | linux/amd64 |
