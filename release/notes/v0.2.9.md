This patch release removes a duplicated heading from the cluster network topology dialog.

## Bug fixes

- Keep a single topology title when the reusable topology view is opened inside the cluster dialog.
- Preserve the standalone topology heading on the settings page, together with node status and view controls. ([#123](https://github.com/smartcat999/game-panel-lite/pull/123))

## Upgrade notes

No data or configuration migration is required. The control plane restarts briefly during the update. Running game server containers and save data are not recreated.

| Compatibility | Result |
| --- | --- |
| Data migration | Not required |
| Configuration migration | Not required |
| Game server restart | Not required |
| Control-plane restart | Required |
| Published platform | linux/amd64 |
