This release makes Don't Starve Together runtime updates self-healing when Steam refuses the stale local depot manifest, and adds the `v2026.10.19` DST runtime image with the latest dedicated server build.

## Bug fixes

- Recover DST servers whose SteamCMD update aborts with `Access Denied` on the installed depot manifest: the entrypoint now quarantines the stale `appmanifest` and re-downloads the current public build instead of failing forever with app state `0x6`. ([#159](https://github.com/smartcat999/game-panel-lite/pull/159))
- Keep DST servers available when every update attempt still fails: start the installed build with a clear warning instead of exiting, and allow opting back into fail-fast behaviour with `DST_GAME_UPDATE_STRICT=1`. ([#159](https://github.com/smartcat999/game-panel-lite/pull/159))
- Make DST runtime image builds resilient to the same stale Steam manifest in the build cache. ([#160](https://github.com/smartcat999/game-panel-lite/pull/160))

## Features

- Add the `v2026.10.19` DST runtime image with the latest Don't Starve Together dedicated server build. ([#160](https://github.com/smartcat999/game-panel-lite/pull/160))
- Default new DST servers to `v2026.10.19` while keeping the older runtime versions selectable for rollback. ([#160](https://github.com/smartcat999/game-panel-lite/pull/160))

## Documentation

- Document dated DST image tags, build retries, and stale manifest handling in the DST image README. ([#160](https://github.com/smartcat999/game-panel-lite/pull/160))

## Upgrade notes

No data or configuration migration is required. Updating the control plane briefly restarts the API and Web services. Existing game server containers and save data are preserved and do not need to be restarted. DST servers that still use an older runtime image can be switched to `v2026.10.19` (or have their runtime image rebuilt) to pick up the latest game build and the entrypoint recovery.

| Compatibility | Result |
| --- | --- |
| Data migration | Not required |
| Configuration migration | Not required |
| Game server restart | Not required |
| Control-plane restart | Required |
| Published platform | linux/amd64 |
