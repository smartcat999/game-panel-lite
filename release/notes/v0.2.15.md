This release makes runtime image management denser, keeps navigation stable, and makes DST restarts safer.

## Improvements

- Simplify runtime image management into a compact four-column list.
- Move the refresh action into the list toolbar and remove the redundant timestamp column.
- Place Runtime Images last in the game asset navigation to match its lower-frequency maintenance role.
- Keep tab typography stable so switching sections no longer shifts neighboring tabs. ([#145](https://github.com/smartcat999/game-panel-lite/pull/145)) by [@smartcat999](https://github.com/smartcat999)
- Gracefully stop the DST Master shard before Caves and allow enough time for Klei lobby cleanup.
- Retry incomplete DST Workshop refreshes and preserve partial downloads so slow updates continue instead of restarting from zero.

## Upgrade notes

No data or configuration migration is required. The control plane restarts briefly during the update. Running game server containers and save data are not recreated.

| Compatibility | Result |
| --- | --- |
| Data migration | Not required |
| Configuration migration | Not required |
| Game server restart | Required only to apply the updated DST runtime |
| Control-plane restart | Required |
| Published platform | linux/amd64 |
