The first versioned GamePanel Lite control-plane release for early self-hosted use.

## Features

- Add authenticated release checks and asynchronous panel updates with persistent job state. ([#85](https://github.com/smartcat999/game-panel-lite/pull/85)) by [@smartcat999](https://github.com/smartcat999)
- Package the V1 multi-instance, configuration, world, backup, mod, monitoring, and provider workflows.

## Bug fixes

- Fix the panel automatic-update switch thumb alignment and disabled state. ([#86](https://github.com/smartcat999/game-panel-lite/pull/86)) by [@smartcat999](https://github.com/smartcat999)

## Deployment notes

- Production uses compose.prod.yaml.
- HTTPS deployments add compose.https.yaml; both files describe the same Nginx service.
- Published control-plane images target linux/amd64.
- Persistent data remains under the installation data directory.

## Known limitations

- Provider capabilities differ by game.
- This is an early self-hosted release; keep an external copy of important worlds and backups.
- Review later patch releases before relying on the initial self-update implementation.
