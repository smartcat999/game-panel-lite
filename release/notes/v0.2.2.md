This patch release fixes Settings navigation on narrow screens.

## Bug fixes

- Replace the fixed mobile tab row with a full-width section selector so labels are never clipped. ([#94](https://github.com/smartcat999/game-panel-lite/pull/94)) by [@smartcat999](https://github.com/smartcat999)
- Keep icon-based horizontal tabs on larger screens and make the section list data-driven for future additions. ([#94](https://github.com/smartcat999/game-panel-lite/pull/94)) by [@smartcat999](https://github.com/smartcat999)

## Known issues

> [!WARNING]
> The v0.2.2 Updater could replace API/Web containers without recreating Nginx, causing temporary HTTP 502 responses. Upgrade to v0.2.3 for the fix.
