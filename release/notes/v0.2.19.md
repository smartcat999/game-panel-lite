GamePanel Lite v0.2.19 adds vanilla 7 Days to Die and Project Zomboid 42.21 servers, native configuration forms and save-management improvements.

## New games

- **7 Days to Die**: vanilla server creation, world/random-map settings, server/advanced/multiplayer groups, Sandbox Code and categorized sandbox options. Game-file updates are separate from runtime-image versions. Base runtime: V3.3.0; match the actual server build to your client.
- **Project Zomboid 42.21**: native server/sandbox groups, search, five verified official presets, vanilla map and eleven default spawn regions. Steam networking uses UDP 16261/16262 inside the container; forward both mapped host ports.
- PZ preserves native world identity when applying settings and restarting. Initial administrator credentials only apply before database creation and are masked in startup output.
- Both new providers require stopped servers for consistent backups. PZ backups contain the complete Zomboid saves, configuration and account databases; game programs are excluded.

## Fixes and validation

- Correct disabled-value validation, configuration layout and runtime-install conflict handling during read-only version checks.
- PZ: verified native startup, clean stop, full backup/restore, unchanged world identity after restart, and user-confirmed joining with a 42.21 Steam client through a public UDP forward.
- Seven Days: verified startup, save loading and normal lifecycle. Steam/EOS connectivity and adequate disk space are required; no claim is made here that every client/version combination has been tested.
- Go tests/vet, 173 frontend tests, typecheck, application-source lint and production build passed. Full frontend lint still reports pre-existing errors in unrelated local scripts.

## Upgrade notes and limitations

Linux AMD64 runtime images. No Workshop/modded-server management, arbitrary console or scheduled live backups for the two new providers. FRP/cloud firewall setup is separate. Large game runtimes require sufficient download/extraction/update space; installing a game is optional.

The panel upgrade recreates control-plane services while preserving existing game containers and saves. Back up panel data before upgrading. Seven Days uses the base port over TCP/UDP and base+1/base+2 over UDP; PZ needs two UDP ports.
