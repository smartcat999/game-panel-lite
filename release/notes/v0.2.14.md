This release improves Don't Starve Together mod reliability and configuration, protects endless worlds during restarts, and makes the control panel denser and more accurate.

## Features

- Add multilingual configuration editing for installed DST Workshop mods, including localized option labels and values. ([#134](https://github.com/smartcat999/game-panel-lite/pull/134)) by [@smartcat999](https://github.com/smartcat999)
- Add Terraria Vanilla 1.4.5.7 and 1.4.5.8 runtime support.

## Bug fixes

- Preserve assigned DST mods during synchronization and keep configured mods visible while the server is starting. ([#132](https://github.com/smartcat999/game-panel-lite/pull/132), [#133](https://github.com/smartcat999/game-panel-lite/pull/133)) by [@smartcat999](https://github.com/smartcat999)
- Parse localized and helper-generated DST mod configuration tables, including mods with non-standard Lua option values. ([#135](https://github.com/smartcat999/game-panel-lite/pull/135), [#136](https://github.com/smartcat999/game-panel-lite/pull/136)) by [@smartcat999](https://github.com/smartcat999)
- Hide instructional preambles embedded in DST mod configuration definitions. ([#137](https://github.com/smartcat999/game-panel-lite/pull/137)) by [@smartcat999](https://github.com/smartcat999)
- Preserve endless DST worlds across restart and keep restart available after Workshop refresh failures. ([#138](https://github.com/smartcat999/game-panel-lite/pull/138)) by [@smartcat999](https://github.com/smartcat999)
- Simplify dashboard node monitoring and consolidate server status and sharing controls. ([#139](https://github.com/smartcat999/game-panel-lite/pull/139), [#140](https://github.com/smartcat999/game-panel-lite/pull/140)) by [@smartcat999](https://github.com/smartcat999)
- Improve settings information architecture, move game runtime images into game assets, and provide a denser compute-node table. ([#141](https://github.com/smartcat999/game-panel-lite/pull/141), [#143](https://github.com/smartcat999/game-panel-lite/pull/143)) by [@smartcat999](https://github.com/smartcat999)
- Display live Docker CPU, memory, and running workload counts for the local compute node. ([#142](https://github.com/smartcat999/game-panel-lite/pull/142)) by [@smartcat999](https://github.com/smartcat999)
- Clarify worker-node removal behavior and correct lifecycle action notifications. ([#131](https://github.com/smartcat999/game-panel-lite/pull/131)) by [@smartcat999](https://github.com/smartcat999)

## Upgrade notes

No data or configuration migration is required. The control plane restarts briefly during the update. Running game server containers and save data are not recreated.

| Compatibility | Result |
| --- | --- |
| Data migration | Not required |
| Configuration migration | Not required |
| Game server restart | Not required |
| Control-plane restart | Required |
| Published platform | linux/amd64 |
