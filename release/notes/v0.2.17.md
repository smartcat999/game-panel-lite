This release introduces a dedicated Updates tab, official character portraits for Don't Starve Together, a scheduled auto-backup system, host/admin protection in player management, and enhanced dashboard monitoring.

## Features

- Add a dedicated **Updates** tab in Settings for panel release checking, version status, and one-click upgrades.
- Add official portraits for all 18 Don't Starve Together characters across player cards and console listings.
- Add scheduled automatic backup system with configurable intervals and retention.
- Add asynchronous in-memory player state caching to reduce game container polling overhead.
- Identify DST host and administrator roles in the player list and prevent accidental kick or ban actions.
- Densify monitoring charts and optimize connection metrics display.
- Add release manifest caching, HTTP 304 conditional request support, and CDN fallback to ensure reliable update checks.
- Dynamically display the active system version in the global command drawer.

## Bug fixes

- Confirm and acknowledge routed DST console commands properly.
- Deduplicate server console log snippets in the control drawer.
- Align server mod installation actions across catalog and instance views.

## Upgrade notes

No data or configuration migration is required. Updating the control plane briefly restarts the API and Web services. Existing game server containers and save data are preserved.

| Compatibility | Result |
| --- | --- |
| Data migration | Not required |
| Configuration migration | Not required |
| Game server restart | Not required |
| Control-plane restart | Required |
| Published platform | linux/amd64 |
