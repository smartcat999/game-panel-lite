This patch release aligns management actions in the web interface with the existing fine-grained permission model.

## Bug fixes

- Keep game rules visible but read-only for viewer accounts, and hide the save action when `server.configure` is unavailable.
- Hide the server-detail cluster management link unless the account can manage nodes and settings.
- Hide fleet settings and add-node actions when their permissions are unavailable, and prevent the add-node dialog from rendering without `node.manage`. ([#121](https://github.com/smartcat999/game-panel-lite/pull/121))

## Upgrade notes

No data or configuration migration is required. The control plane restarts briefly during the update. Running game server containers and save data are not recreated.

| Compatibility | Result |
| --- | --- |
| Data migration | Not required |
| Configuration migration | Not required |
| Game server restart | Not required |
| Control-plane restart | Required |
| Published platform | linux/amd64 |
