This maintenance release stabilizes the server detail navigation while provider capabilities are loading.

## Fixes

- Prevent capability-dependent tabs from briefly showing controls that the selected game provider does not support.
- Keep the navigation area stable with a fixed-height loading placeholder until provider capabilities are available. ([#127](https://github.com/smartcat999/game-panel-lite/pull/127))

## Upgrade notes

No data or configuration migration is required. The control plane restarts briefly during the update. Running game server containers and save data are not recreated.

| Compatibility | Result |
| --- | --- |
| Data migration | Not required |
| Configuration migration | Not required |
| Game server restart | Not required |
| Control-plane restart | Required |
| Published platform | linux/amd64 |
