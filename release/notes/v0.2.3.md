GamePanel Lite v0.2.3 fixes the control-plane update handoff after container replacement.

## Changes

- Force-recreates Nginx together with API, Web, and Exporter during panel updates.
- Prevents Nginx from retaining stale upstream container IP addresses after an update.
- Adds a regression test for the required update service set and force-recreate flag.
- Removes duplicated release-title headings from the stored v0.2.x release notes.

---

## 中文说明

GamePanel Lite v0.2.3 修复控制平面容器更新后的反向代理切换问题。

### 主要变化

- 面板更新时同时强制重建 Nginx、API、Web 和 Exporter。
- 避免 Nginx 在容器更新后继续访问旧的上游容器 IP。
- 增加更新服务集合与强制重建参数的回归测试。
- 移除 v0.2.x 版本说明文件中的重复标题。
