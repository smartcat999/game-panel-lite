GamePanel Lite v0.2.1 is a maintenance release focused on control-plane operations, deployment portability, and interface stability.

## Changes

- Added General, Access & HTTPS, and Updates & Maintenance sections to Settings.
- Added authenticated control-plane service status, recovery, and confirmed restart operations.
- Added HTTPS certificate inspection, manual renewal checks, and observable automatic-renewal status.
- Added a daily Updater renewal scheduler that defers to an existing systemd timer.
- Decoupled deployment status from Docker Compose through manager and capability reporting, including standalone-process health probes.
- Added expandable maintenance error details while keeping normal feedback compact.
- Stabilized server resource columns and clarified CPU and memory usage.
- Corrected project license labels to Apache License 2.0.
- Reworked the English and Chinese README for installation and operations.

## Upgrade

Open **Settings → Updates & Maintenance**, select **Check for updates**, and install v0.2.1. Running game server containers and save data are not recreated by the panel update.

## 中文说明

GamePanel Lite v0.2.1 是一个维护版本，重点完善控制平面运维、部署方式兼容和界面稳定性。

### 主要变化

- 设置页新增“基本设置 / 访问与 HTTPS / 更新与维护”。
- 新增控制平面组件状态、恢复服务和确认重启。
- 新增 HTTPS 证书状态、手动续期检查和自动续签状态展示。
- Updater 支持每日续签调度，并在已有 systemd timer 时自动让位。
- 使用部署驱动和 capabilities 描述能力，不再强制绑定 Docker Compose。
- 维护任务失败时可以展开查看原始错误详情。
- 稳定服务器资源列，并明确区分 CPU 与内存用量。
- 将项目许可证标识修正为 Apache License 2.0。
- 重构中英文 README 的安装与运维说明。

### 更新方法

进入 **设置 → 更新与维护**，点击 **检查更新** 并安装 v0.2.1。面板更新不会重建运行中的游戏服务器容器，也不会修改存档。
