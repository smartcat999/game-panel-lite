This maintenance release removes duplicated game settings from the server detail experience and makes configuration changes safer.

## Fixes

- Keep the server lobby focused on runtime status, deployment topology, networking, and recent operations.
- Consolidate curated game rules and provider settings into one configuration draft with one save action.
- Prevent common Terraria, Palworld, Minecraft, and Don't Starve Together settings from appearing in multiple editors.
- Avoid stale configuration drafts overwriting changes saved from another section. ([#129](https://github.com/smartcat999/game-panel-lite/pull/129))

## Upgrade notes

No data or configuration migration is required. The control plane restarts briefly during the update. Running game server containers and save data are not recreated.

| Compatibility | Result |
| --- | --- |
| Data migration | Not required |
| Configuration migration | Not required |
| Game server restart | Not required |
| Control-plane restart | Required |
| Published platform | linux/amd64 |
