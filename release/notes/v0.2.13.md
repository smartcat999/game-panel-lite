This release improves security and destructive operational safety across cluster management and server lobbies.

## Highlights

- **Server Password Masking & Zero Layout Shift**: Server join passwords are now masked with `••••••••` by default in the server lobby banner, with an eye toggle button to reveal on demand. The container width is stabilized to eliminate layout shifts when toggling.
- **Safe Compute Node Removal Modal**: Replaced native browser confirm dialogs with a high-contrast dark confirmation modal featuring danger warnings and active workload risk reminders before node deregistration.

## Fixes & Improvements

- Mask sensitive game server join passwords by default to prevent accidental leakage during streaming or screenshot sharing.
- Fix UI layout jitter and button displacement when toggling between masked and plain text passwords in the lobby banner.
- Add destructive action safeguards when deleting remote compute nodes, warning users of potential workload detachment if active game instances are running.
- Ensure proper root portal rendering for critical cluster modal dialogues.

## Upgrade notes

No data or configuration migration is required. The control plane restarts briefly during the update. Running game server containers and save data are not recreated.

| Compatibility | Result |
| --- | --- |
| Data migration | Not required |
| Configuration migration | Not required |
| Game server restart | Not required |
| Control-plane restart | Required |
| Published platform | linux/amd64 |
