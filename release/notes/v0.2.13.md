This maintenance release improves privacy protection in server lobbies and operational safety for cluster node management.

## Highlights

- **Server join password privacy**: Mask sensitive join passwords by default in server lobby banners with an eye toggle to reveal on demand, preventing accidental leakage during streaming or screenshot sharing.
- **Zero layout shift on password toggle**: Stabilize the password pill container width to eliminate layout shifts and button displacement when toggling between masked and plain text.
- **Safe compute node removal**: Replace native browser confirm dialogs with a high-contrast dark confirmation modal featuring active workload risk warnings.

## Features

- Mask server join passwords with `••••••••` by default in the server lobby banner, providing an interactive eye toggle for instant display. by [@smartcat999](https://github.com/smartcat999)
- Introduce a dedicated high-contrast destructive confirmation modal for removing remote compute nodes, warning users of potential workload detachment if active game server instances are running. by [@smartcat999](https://github.com/smartcat999)

## Bug fixes

- Fix layout jitter and button displacement in the lobby banner by setting a stable minimum width and right-aligned layout for the password display pill. by [@smartcat999](https://github.com/smartcat999)
- Ensure critical cluster management modals are mounted via root portals to avoid visual clipping under backdrop filter headers. by [@smartcat999](https://github.com/smartcat999)

## Upgrade notes

No data or configuration migration is required. The control plane restarts briefly during the update. Running game server containers and save data are not recreated.

| Compatibility | Result |
| --- | --- |
| Data migration | Not required |
| Configuration migration | Not required |
| Game server restart | Not required |
| Control-plane restart | Required |
