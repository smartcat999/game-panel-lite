This release adds first-class seasonal event controls for Don't Starve Together servers.

## Features

- Add a dedicated seasonal events section to DST game rules.
- Follow the official event included in the current game build, or disable it explicitly.
- Enable any combination of 13 additional seasonal events without regenerating the world.
- Use the provider schema as the source of truth for event availability and bilingual names. ([#125](https://github.com/smartcat999/game-panel-lite/pull/125))

## Reliability

- Preserve existing world overrides when updating deeply nested provider settings.
- Render seasonal choices into the Master world's `leveldataoverride.lua` configuration.

## Upgrade notes

No data or configuration migration is required. The control plane restarts briefly during the update. Running game server containers and save data are not recreated by the control-plane deployment. DST seasonal event changes take effect after the affected game server is restarted.

| Compatibility | Result |
| --- | --- |
| Data migration | Not required |
| Configuration migration | Not required |
| Game server restart for upgrade | Not required |
| Control-plane restart | Required |
| Published platform | linux/amd64 |
