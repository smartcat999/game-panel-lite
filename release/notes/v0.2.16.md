This release adds a focused Don't Starve Together administration console and improves server setup feedback.

## Improvements

- Add a side drawer for common DST operations, including saves, backups, announcements, rollback, and shard-aware terminal commands.
- Keep the existing server detail tabs and logs available while the console is open.
- Show the console entry while a DST server is stopped so administrators can inspect the available controls.
- Report runtime image installation progress instead of leaving the install action without visible feedback.
- Align provider configuration fields and use clearer surface-world and caves terminology.
- Allow server creation while a read-only provider version check is running; actual updates and world maintenance still block creation.

## Upgrade notes

No data or configuration migration is required. Updating the control plane briefly restarts the API and Web services. Existing game server containers and save data are preserved.

| Compatibility | Result |
| --- | --- |
| Data migration | Not required |
| Configuration migration | Not required |
| Game server restart | Not required |
| Control-plane restart | Required |
| Published platform | linux/amd64 |
