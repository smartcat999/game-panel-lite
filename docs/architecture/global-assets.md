# 全局已发布资产版本

全局目录管理资产身份、组织归属，以及不可变版本的 SHA-256 摘要与字节大小；不保存宿主机路径、上传会话或区域存储地址。Region 管理实际内容及副本完整性。已发布版本不表示某个 Region 已经拥有文件，也不授予游戏进程写入权。

`PublishAssetVersion` 是受信内容接入边界：调用方必须完成内容校验与租户授权后才能登记，不允许公共 API 将客户端自报摘要当作校验证据。相同身份和版本的相同元数据可重复提交；不同组织不能抢占同一资产身份，已有版本不能更换摘要或大小。新版本追加登记，旧版本保持不变。目前尚未接入真实上传、病毒／格式检查、区域验证回报、撤销或保留期清理流程。

PostgreSQL 018／SQLite 版本 6 新增 global_assets 与 global_asset_versions，使用主键和数据库触发器固定归属与已发布内容。SQLite 同时防止 INSERT OR REPLACE 更换内容或归属。历史迁移不变，旧 ModFile 不自动转换为已验证的全局版本。后续撤销和 GC 必须引入显式生命周期与引用保留协议，不能直接删除不可变目录。

受保护创建和配置更新在现有权限、幂等及事务边界内检查资产引用。每批最多 100 个引用：先按组织与资产 ID 批量读取身份，再按精确 ID／版本对查询版本；两次查询均为单表，代码核对完整集合，无 JOIN、跨表子查询或逐资产查询。规格校验已禁止同一资产重复引用，因此有主键保障时返回数量不足即拒绝。精确版本对查询避免读取该资产的所有历史版本。

缺失资产、缺失版本及跨租户引用统一返回不可用，拒绝发生在加密与写入新修订之前。授权重放仍优先返回原操作；旧不透明内部写入接口保留兼容行为，不作为新公共入口。当前没有共享资产授权模型；只允许所属组织引用，跨组织共享需显式授权协议。

测试检查 101 个引用产生四次实际查询，并覆盖受保护创建／更新的越权和缺失引用拒绝、真实加密修订保留资产引用、重复发布、版本冲突及不可变约束。它不替代执行计划、生产数据规模测试或区域内容交付验收。

## 区域修订资产清单

GetRegionalRevision 先验证服务身份对应的 Region、原 Outbox 事件、租户实例及当前 Placement，再在同一只读快照内解析该不可变修订所引用的精确资产版本。复用批量单表查询，以代码映射保留引用顺序，返回 organizationId、assetId、version、sha256、sizeBytes；缺失、越权或非法目录数据一律拒绝，不返回部分配置或资产清单。旧内部写入路径未检查的资产引用也不能绕过此读取边界。

RevisionSnapshot 新增 assets 清单。区域客户端和持久化边界要求清单与修订资产引用构成完整的一一对应：拒绝遗漏、多余、重复、错版本、错租户、非法摘要或负大小。没有资产引用的旧快照仍可读；有引用却缺少清单的旧快照不满足新校验，后续处理前必须重新从授权全局接口获取，不能把缺失清单视作空资产集。升级时暂停后续物化处理，使用下述工具补齐历史快照。

资产清单通过现有 mTLS 修订接口获取并随快照落入区域数据库，不进入通知消息、不提供下载地址或文件内容，也不代表通过本地字节校验或获得执行权限。旧客户端可能忽略新增字段，进入后续资产物化／执行链路前必须升级到验证完整清单的版本。真实 PostgreSQL／mTLS 组合测试使用测试发布元数据，证明传输与落库，不冒充真实世界文件上传和分发验收。

## 旧快照授权补取

受信运维命令使用已绑定 Region 身份的区域数据库，默认只报告。数据库连接由 `GAMEPANEL_REGIONAL_DATABASE_URL` 注入，不放入命令参数或提交配置。先运行预览，再用 `-apply` 将符合条件的任务重新排队：

```sh
go run ./apps/api/cmd/region-repair-manifests -region east -batch-size 20
go run ./apps/api/cmd/region-repair-manifests -region east -batch-size 20 -apply
```

每批按 Operation ID 游标查询最多 100 行，单表事务内锁定 revision_fetched 任务；只有快照身份／版本有效且整份清单缺失才进入 awaiting_revision。保留原通知、操作 ID、尝试次数及旧快照，清除旧领取信息并使重试立即可用。并发执行不会重复重置同一任务；已物化、拒绝、正在等待获取的任务均不改写。超过 4 MiB、非法 JSON、错误身份或部分清单损坏列入 invalid，由运维另行调查；不从部分数据推断修复。

标准输出逐批给出 scanned、candidates、invalid、next、applied，不输出配置或数据库连接。中断后可用最后一个已报告的 next 作为 `-after` 恢复；提交后报告前中断时重复执行也安全。游标扫描不是整个数据库的时间点快照，运行结束后从头预览，检查并发新增记录。`-timeout` 限制修复循环总时间（数据库打开另有连接超时）。

随后由已升级 region-fetcher 经现有 mTLS 接口重新验证当前 Placement／租户／版本，成功才替换旧快照。全局不可用或授权已撤销时保留待获取和重试状态，不伪造成功。重新排队不证明补取完成，也不证明已有进程停止或可释放资源。

## 指定资产的区域访问校验

`ResolveRegionalAsset` 为后续下载授权提供受信内部读取接口。它与修订获取共享同一事务快照内的服务 Region、原事件、租户实例、当前 Placement／epoch 及不可变修订校验，随后要求请求的资产 ID／版本确实被该修订引用，再按所属组织和精确版本读取发布元数据。即使同属该租户，未被引用的资产也拒绝；同一资产的新版本不能借旧修订获取。

接口只解析被请求的资产目录项，不重新读取所有引用的目录内容，仍使用单表查询，不引入 JOIN 或跨业务表关联子查询。旧 Region、旧 Placement epoch、伪造事件、删除实例和旧兼容写入产生的越权引用均拒绝，失败返回空元数据。

返回值是当前读取时点通过校验的元数据，不是可缓存复用的下载令牌、文件地址或执行授权。尚未接入外部下载接口；后续必须将经认证的服务身份、源副本和有界传输授权绑定，不能把客户端自报 Region 或此前一次成功解析当作永久访问权。目录内容不经全局控制面转发，实际文件仍由区域存储交付。

全局控制面现提供 `POST /internal/region/assets/resolve?assetId=…&version=…`，请求正文为原 RevisionAvailable 事件。服务身份从已验证的 mTLS URI SAN 映射取得，不能由 Header 或参数指定；事件 Region 必须匹配身份。只接受单一 assetId／version 参数、有界 JSON 正文和无重复字段的事件。响应设置 no-store，仅包含经 Store 校验的 PublishedVersion；不可用、身份不符、输入错误和内部失败分别返回对应 HTTP 错误，不回显数据库细节。

`controlclient.ResolveAsset` 使用现有受信 HTTPS origin、客户端证书和 CA、超时、无代理及禁止重定向策略，并限制响应体大小。客户端复核租户、资产 ID、版本、摘要／大小格式，拒绝错误身份、未知字段、尾随 JSON 和超限响应，不返回部分元数据。global-control 同时挂载修订与资产解析路由；此 API 仍不是文件下载服务或传输票据服务。
