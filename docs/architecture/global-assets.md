# 全局已发布资产版本

全局目录管理资产身份、组织归属，以及不可变版本的 SHA-256 摘要与字节大小；不保存宿主机路径、上传会话或区域存储地址。Region 管理实际内容及副本完整性。已发布版本不表示某个 Region 已经拥有文件，也不授予游戏进程写入权。

`PublishAssetVersion` 是受信内容接入边界：调用方必须完成内容校验与租户授权后才能登记，不允许公共 API 将客户端自报摘要当作校验证据。相同身份和版本的相同元数据可重复提交；不同组织不能抢占同一资产身份，已有版本不能更换摘要或大小。新版本追加登记，旧版本保持不变。目前尚未接入真实上传、病毒／格式检查、区域验证回报、撤销或保留期清理流程。

PostgreSQL 018／SQLite 版本 6 新增 global_assets 与 global_asset_versions，使用主键和数据库触发器固定归属与已发布内容。SQLite 同时防止 INSERT OR REPLACE 更换内容或归属。历史迁移不变，旧 ModFile 不自动转换为已验证的全局版本。后续撤销和 GC 必须引入显式生命周期与引用保留协议，不能直接删除不可变目录。

受保护创建和配置更新在现有权限、幂等及事务边界内检查资产引用。每批最多 100 个引用：先按组织与资产 ID 批量读取身份，再按精确 ID／版本对查询版本；两次查询均为单表，代码核对完整集合，无 JOIN、跨表子查询或逐资产查询。规格校验已禁止同一资产重复引用，因此有主键保障时返回数量不足即拒绝。精确版本对查询避免读取该资产的所有历史版本。

缺失资产、缺失版本及跨租户引用统一返回不可用，拒绝发生在加密与写入新修订之前。授权重放仍优先返回原操作；旧不透明内部写入接口保留兼容行为，不作为新公共入口。当前没有共享资产授权模型；只允许所属组织引用，跨组织共享需显式授权协议。

测试检查 101 个引用产生四次实际查询，并覆盖受保护创建／更新的越权和缺失引用拒绝、真实加密修订保留资产引用、重复发布、版本冲突及不可变约束。它不替代执行计划、生产数据规模测试或区域内容交付验收。
