# 短期资产传输票据

transferauth 模块在全局签发、在源存储验证 Ed25519 票据。私钥由全局部署外部注入；源端只配置公钥集合，不能自行签发。构造时复制私钥及公钥状态，不依赖调用方可变密钥切片，不生成默认密钥或保存测试密钥。用途固定为 gamepanel.asset-transfer.v1，不能当作执行租约。

Issuer.Issue 不接受客户端自报 AssetSourceSnapshot，必须通过消费接口调用当前 Store 源副本联合校验。票据绑定原事件、目标 Region、租户、资产精确版本／摘要／大小、源副本 ID／观测版本、源 Region 和 StorageID，以及用途、格式版本、keyId、随机票据 ID、签发与到期时间。

TTL 从权限查询开始之前计时，不在查询返回后重新开始。查询超时、时钟回退、到期或权限拒绝均不签发；配置要求毫秒粒度、至少 1 ms、最多 1 h，并显式限制票据最大字节数。实际部署应按传输需要配置较短期限，不能用最大上限作为默认授权时长。

Verifier 校验签名、规范 JSON 编码、用途／格式、完整源绑定、时间范围与本地最大 TTL；拒绝重复字段、别名、未知扩展和错误身份。验证端绑定自身 Region／StorageID，并要求传入经 mTLS 认证的请求 Region，不能采用 Header 或票据内自报身份。无时钟宽限，部署需保证时钟同步；超出期限或尚未生效均拒绝。

票据允许同一授权 Region 在期限内重试，不提供单次消费语义，也不包含文件路径或任意下载 URL。源服务还需核对本地副本并校验文件，且必须把整个传输截止时间限制到 ExpiresAtMS；仅在开始下载时检查票据不足以满足有界授权。已有票据不会因为全局后续目录变化立即失效，撤销窗口由 TTL 限定，源端本地策略仍可提前拒绝。

当前完成签发／验证模块与真实 SQLite／PostgreSQL 权限解析组合，尚未接入签发 HTTP、源端下载服务、传输期限强制关闭、部署密钥装载与轮换／撤销操作流程。验证公钥可保留历史 keyId，但在线轮换和运营流程未验收。票据未加密，不能写入普通日志或放入 URL；后续传输应使用经验证的 HTTPS 服务与合适的请求头／正文。

测试覆盖身份绑定、篡改、错误用途／格式、重复签名字段、时间与 TTL、密钥状态复制、重新签发再次授权，以及目录下架后拒绝新签发。不以这些测试证明跨主机文件传输、时钟漂移容忍、密钥托管或完整生产授权链路。
