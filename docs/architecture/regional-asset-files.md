# 区域资产文件存储

`assetfiles.Store` 是区域私有目录的本地文件 Adapter，仅接受已授权的 PublishedVersion 和内容流。它不依赖 Docker、数据库或 HTTP；真实内容来源由后续交付编排提供，不把旧节点任务接口用作全局资产授权。区域目录由部署配置给出且必须预先存在，租户请求不能提供路径。

Put 接管源流的关闭责任。内容先进入随机命名、0600 权限的临时文件，以固定大小缓冲区流式写入和计算 SHA-256。先限制到声明长度，再探测最多一个额外字节；短文件、超长文件、摘要不符、读取／关闭失败或取消均不发布，并清理本次临时文件。配置限制单个文件最大字节数，支持摘要正确的空内容。

验证完成后同步文件，在同一受限根目录中原子重命名为最终文件，再同步目录。最终名称由完整组织／资产／版本／摘要／大小生成，任何业务 ID 都不会直接成为路径片段。同一清单并发写入允许重复成功，不会暴露半个文件；失败的新写入不会覆盖已有完整内容。若重命名成功后目录同步失败，文件可能已可见但调用返回失败，重试相同清单安全。

Open 使用完整清单定位，只读取普通文件，重新检查大小与摘要后才返回位于文件开头的只读句柄。不同租户或版本不会命中同一记录；损坏数据和符号链接拒绝读取。存储目录必须由本模块独占管理，不支持外部进程在原文件上并发写入。此约束不代替租户权限检查，知道清单不能自动取得读取权限。

取消通过关闭源流解除阻塞，源流 Close 必须能与 Read 并发并使其返回，例如 HTTP 响应体。源请求的建连和截止时间属于内容来源 Adapter；本模块不自行发起网络访问。存储读取发生本地磁盘 I/O，取消在读取边界检查，不声明可以中断任意内核文件操作。

测试使用真实临时文件系统，覆盖并发发布、摘要／长度／源错误、取消解除阻塞、半成品不可读、原文件保留、身份隔离、损坏和符号链接拒绝、空内容及关闭后重新打开。它不替代进程强杀、断电／磁盘故障或跨主机交付验收。

本地 Adapter 不直接修改区域任务，持久编排见下文；Replica 元数据和下载服务尚未接入，不能据此把 revision_fetched 提升为可执行。后续需补充源授权、区域副本目录、总存储配额、并发背压、崩溃后遗留临时文件回收、保留期与 GC；没有自动删除其他任务或历史文件，也不向用户返回宿主机绝对路径。

## 修订资产准备编排

`regional.AssetPreparer` 通过消费接口组合 AssetSource 与 AssetFiles，接入真实 assetfiles.Store。它先验证快照身份、完整清单及目标 Region，再检查整个清单的文件数量、单文件和总字节限制，所有检查完成前不打开任何源流。总量采用剩余额度逐项扣减，防止整数加法溢出。

每次准备有统一截止时间，逐项获取并校验发布，最多一个活动内容流；源接口必须基于原事件及精确资产版本重新验证当前访问授权，不能把持有快照当作下载凭证。已有本地文件也不跳过此授权步骤。当前尚未提供生产网络 AssetSource，测试来源明确为夹具，不能作为已实现跨 Region 下载授权的证据。

前几个文件成功而后续失败时，整个 Prepare 返回失败，已校验文件可保留以供重试和后续 GC。重试仍经过源授权，文件准备成功不改变任务状态、全局意图、租约或执行权限。测试通过真实文件 Adapter 验证中途摘要失败、重试成功、缓存存在时授权拒绝仍失败、整批超限在 I/O 前拒绝和超时关闭阻塞流。每次准备的总字节限制不是区域磁盘总配额，持久任务、区域副本目录及总容量预留仍需接入。

## 持久资产准备任务

区域迁移 003 为 regional_revision_tasks 增加独立资产领取 token、租约截止时间、下次重试时间和尝试次数，并增加 assets_prepared 状态及准备队列索引。修订获取仍使用原有计数，两阶段互不替代。历史迁移字节不变；升级应迁移区域数据库后统一启动匹配版本，旧进程不能当作支持新生命周期的执行者。

ClaimAssets 使用单表行锁和 SKIP LOCKED 领取 revision_fetched 任务，在锁内按数据库时间建立租约，并验证持久事件、Region 与完整快照。损坏／缺清单的记录持久延后一个领取租约时长并报告错误，避免一直占据队首；运维仍需使用修复或调查流程。快照读取有 4 MiB 上限，超限不解析为准备任务。

AssetWorker 在事务外调用准备模块，失败保存重试时间；成功在另一个事务内按原 token、事件、完整快照与当前数据库时间复核后才能标记 assets_prepared。过期领取、篡改快照或修订重新获取前的旧领取不能完成任务。重新打开数据库后可领取过期任务；实际文件已写入而任务尚未完成时允许重新授权和校验，不把文件存在当作持久任务完成。

assets_prepared 仅记录配置的区域存储完成该清单准备，不是部署／运行授权或节点已拥有副本的证明。当前尚未接入生产下载源及独立资产 Worker CLI，区域副本目录、存储卷身份、容量预留和跨主机可访问性仍需完成。多个进程不能把各自不共享的本地目录当作同一可用存储；后续物化前必须核验目标可访问的副本及执行授权。测试使用真实 PostgreSQL 和文件 Adapter、夹具内容源，覆盖并发唯一领取、租约过期与重连、重试、快照替换拒绝和成功状态，不冒充进程强杀或跨主机验收。
