GamePanel Cloud：饥荒原生 ZIP 导入与备份调整清单
日期：2026-11-14
范围：Cloud 后续工作，本次未修改 Cloud 代码或部署。

输入约定
Lite 新备份使用标准 ZIP，以原生集群名称为顶层目录，例如：
  我的集群/cluster.ini
  我的集群/Master/server.ini
  我的集群/Master/modoverrides.lua
  我的集群/Master/save/...
  我的集群/Caves/server.ini
  我的集群/Caves/modoverrides.lua
  我的集群/Caves/save/...
洞穴可能未启用，不应强制要求 Caves。包内没有必须由面板解释的私有清单。
集群内其他原生文件按原样保留，包括可能存在的令牌文件；不要输出其内容或默认用于测试服联网。

1. 原生 ZIP 与目录识别（必需）
同时接受 ZIP、tar.gz/tgz；识别集群目录，而不是只接受 Cloud 工作目录布局。
支持 Lite 新格式，以及旧 dst/<集群名>/... 布局；不能强制顶层叫 Cluster_1。
识别多个集群时让用户选择，不能猜测；不完整目录明确提示。
识别后映射到目标集群路径，保留 Master/Caves、玩家与世界数据，不能生成空世界替代导入失败。
恢复完成后应替换对应存档目录，避免残留比备份更新的快照。

2. 解包路径规范化（P1，已复现）
Extra Equip Slots 的四个资产路径使用反斜杠，例如 images\back.tex。
Cloud 解包后保留了字面反斜杠，游戏却读取 images/back.tex，导致 Lua 加载错误。
应先规范分隔符，再检查绝对路径、盘符、.. 穿越、符号链接及规范化后同名冲突。
应在统一解包层修复，不要求用户改模组或写启动脚本。

3. 版本检查及模组迁移（P1，实际迁移未无损通过）
本次原服游戏版本 760178，Cloud latest 下载到 762172。
地上、洞穴均加载到第 932 天，但地上两条 blueprint 记录加载失败，原服日志无同类记录。
这说明当前结果不能视为无损迁移；版本差异与错误同时存在，具体因果尚未确认。
导入时展示源/目标版本；无法从原生文件识别版本时应明确“未知”，允许用户指定，不能将未知标为兼容。
避免静默使用 latest；提供明确版本或已保存的不可变运行包引用。
从原生 modoverrides.lua 等文件安全解析模组 ID 与配置，不能直接执行上传的 Lua。
下载前展示模组清单及版本差异；无法取得原模组版本时明确提示，不承诺配置相同就代表行为相同。
不应强制 Lite 添加私有格式或把可选版本说明文件变成导入前置条件。

4. 房间设置与令牌的恢复预览
当前 Cloud 会重新生成 cluster.ini 和两个 server.ini，直接恢复不会自动保留全部源设置。
导入前逐项说明保留、映射或重新填写的设置：名称、密码、玩法、人数、洞穴、端口等。
网络端口按目标分配映射，洞穴身份保持一致。
令牌不得出现在日志、预览明文或公开分享页；测试服不要自动联网注册原房间。

5. 在线备份保存协调（P1）
不能把“命令已发送”或固定等待几秒视为保存完成。
需要确认所有启用分片的本次保存完成后再打包；失败、超时、掉线时不发布成功备份。
采用本次请求唯一标识，避免历史日志误判；仅在游戏真实完成的回调后确认。
在线保存确认不等于跨分片事务快照；严格一致的正式迁移应在保存后停服再导出。

6. 资源预检与真实就绪状态
本次双世界、17 模组在 4 GB 下 OOM，退出 137；8 GB 时加载完成，观测约 4.7 GB。
这是本次存档的实测，不应推广为所有饥荒服必须 8 GB。
创建/导入时结合洞穴、模组、源资源信息给出建议。
容器 Running 不能等同于游戏就绪；应区分下载、加载、双世界就绪、Lua 错误和 OOM 重启。

7. 下载及停服反馈
顶部优先显示当前处理的任务，区分排队、下载、校验、待应用与实际已加载；补充整体进度。
模组配置保存成功不能直接显示为已安装完成。
本次停服短暂显示 context deadline exceeded，但容器实际退出 0，随后才收敛到已停止。
应协调请求超时和停服等待时间，并确认实际退出状态，避免用户误以为需要强杀。

8. 创建及脚本编辑体验
提供“创建后导入存档”的流程，不应强制先启动一个空世界。
多行启动脚本应使用多行编辑器，避免 HTML 单行输入框丢失换行。
模板托管字段应说明哪些会重新生成、哪些允许实例覆盖，避免用户保存后配置失效。

验收建议
原生 ZIP 及旧 Lite ZIP、中文/不同集群名、仅地上/双世界、恶意路径、目录冲突均需覆盖。
保存确认应覆盖缺分片、错误、超时、旧日志以及确认前不得生成备份。
迁移验收分别核对文件、游戏和模组版本、实际世界加载、分片连接、客户端加入。
