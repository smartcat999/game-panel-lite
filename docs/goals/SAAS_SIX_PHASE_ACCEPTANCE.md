# 六阶段 Goal 验收矩阵

2026-09-08。目标：完成已确认的多租户、多 Region 托管 SaaS 全部六阶段改造。每阶段是检查点；本矩阵全部要求获得匹配证据前不得关闭总 Goal。权威设计为 [目标蓝图](../architecture/architecture-target-blueprint.md) 和 [ADR-0001](../adr/0001-global-resources-regional-execution.md)。资源层级仅 Region → Node，全局拥有逻辑实例及配置。

状态含义：待实现、部分实现、待验收、已验收。历史测试只证明其覆盖范围；下列没有完整证据的要求均保持未完成。详细局部证据见 [进度记录](SAAS_REFACTOR_PROGRESS.md)。

## 初始工作区分类

- 端口批次：主/附加端口持久预留、SQL 014 / SQLite 版本 2 回填、租约授权删除回报释放、并发与迁移测试；已以 `64811a9f` 提交，独立快照全量 Go、vet、真实 PostgreSQL race 通过。
- 调度草稿：scheduler、app/HTTP 接线、节点 cordon/drain、区域过滤及界面。CPU/内存候选与 Store 已接入共享纯规则；尚无全局/区域实体分离及严格区域调度契约。
- 商业/身份草稿：credits、OAuth、模型与界面。已存在余额一致性修复，费用硬编码和真实商业验收未完成。
- 文档：术语、ADR、蓝图及早期方案优先级更新，描述目标，不代表实现。
- 用户媒体及演示脚本：不属于本次 SaaS 改造，保持原样，不纳入功能提交。

## 跨阶段执行与完成门槛

- 每批运行 gofmt、go test ./...、go vet ./...、架构依赖门禁及适用并发测试；前端变更运行 lint/typecheck/build 与主要旅程验证。失败先定位，环境缺失记录原因，不伪造通过。
- 提交必须与验证快照匹配；不 push、不上线、不购买资源、不真实扣款。保留用户媒体/脚本及无关修改。
- 本地模拟、同机 Docker、真实独立主机、支付沙箱、生产和规模验收分别标注。证据包括日期、版本/提交、命令、环境、原始结果与范围限制。
- 外部需求逐项登记：支付账户与回调域名；跨主机/两区域资源；千/万实例容量与预算；价格及保留策略的发布确认。未满足时继续独立工作，不能把总目标缩成可通过的小目标。
- 最终交付源码、迁移、部署配置、运行说明、提交清单、测试证据和限制。所有未完成项清零且证据范围匹配后才完成 Goal。
